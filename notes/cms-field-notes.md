# CMS field notes — WordPress Playground

Tried WordPress Playground (playground.wordpress.net) on Oct 6, 2026, logged in as admin and then as an Editor user I made.

## 1. Drafts
The draft didn't show on the site; I had to look for the preview button. It is a very simple software, but very functional. The UI is very easy as well. It would take a lot of time to create a very complex UI website.

## 2. Publishing a post
After publishing, it's at the top, above the WordPress "Hello world". It shows the full text, the title and then "written by admin in Uncategorized". Then it shows the full text, no preview link.

## 3. Pages vs posts
The page is different. No author. There is a top bar with my WordPress website and a link to itself, with a Hello world link and a Sample Page link, and About shows up there too. On the page I also cannot see the previous posts.

## 4. Slugs / permalinks
Posts use "Day and name", so the URL has the date and then the title: `.../2026/10/06/sample-post/`. The page URL is just `.../about/` with no date. The title gets turned into lowercase with hyphens.

## 5. Editor role
Logged in as the editor (iphs). The sidebar only has Dashboard, Posts, Media, Pages, Comments, Profile, Tools. There's no Users. When I typed `/wp-admin/users.php` into the address bar I got "You need a higher level of permission. Sorry, you are not allowed to list users." The editor also sees "WordPress 7.1.3 is available! Please notify the site administrator."

I think people would know what to do here. They could reach out to the admin and ask for higher permissions based off this. But the page doesn't say who the admin is or how to reach them.

## 6. Content list (Posts → All Posts)
Categories, tags, and bulk actions wouldn't make much sense to someone without a technical background. Status is difficult to see, it's very small. I don't know if the editor should see everyone's posts, it could cause clutter with deleting other people's notes.
